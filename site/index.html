packgate

Fail CI when npm pack, pnpm pack, or yarn pack would ship secrets, untracked files, or drop the files your package claims to export.

.gitignore does not decide what a registry upload contains. packgate inspects the tarball those pack commands actually write.

Use it without creating accounts

GitHub is the distribution channel. No npmjs login.

npx --yes github:cocabot/gro
- uses: cocabot/gro@v0.2.0
- repo: https://github.com/cocabot/gro
  rev: v0.2.0
  hooks:
    - id: packgate
